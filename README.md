# OsdagBridge – Software Testing Repository

## 1. Project Overview

This repository contains the software testing documentation, test cases, execution evidence, and validation records for **OsdagBridge**, a bridge design and analysis application.

The purpose of this testing activity is to evaluate the application's functionality, input handling, design execution, output generation, and consistency of results under different test conditions.

This repository serves as a centralised record of the testing process, observations, execution results, and supporting evidence.

## 2. Source Project

The original OsdagBridge software repository is available here:

[OsdagBridge – Source Repository](https://github.com/anonymouscoder999/OsdagBridge)

## 3. Repository Structure

The repository is organised into the following directories and files:

| Directory / File | Description |

| `01_Basic_Test/` | Contains basic testing-related files and supporting materials. |

## 4. Testing Scope

The testing activity covers the following areas:

- Basic input validation.
- Bridge geometry and design configuration.
- 3D model generation.
- Design execution and result generation.
- Changes in input parameters and their corresponding outputs.
- Design report generation.
- Repeated execution and consistency checks.
- Input-output dictionary comparison.

## 5. Test Case Documentation

The project includes test cases TC01 to TC12.
